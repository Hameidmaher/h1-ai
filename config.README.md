# H1-AI Configuration Guide

All settings are managed from `config.production.yaml`.

## Critical Fields

| Field | Description | Example |
|-------|-------------|---------|
| app.name | App name | H1-AI |
| app.domain | Domain | h1-ai.com |
| whatsapp.phone | WhatsApp number | +201234567890 |
| llm.provider | AI provider | ollama |
| backend.deployment | Where to deploy | local |
